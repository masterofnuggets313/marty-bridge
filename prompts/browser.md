# Браузер: рабочие рецепты

Сценарий для агента: разведка, действие, проверка. Ниже то, что проверено
на живых страницах.

## Разведка перед первым кликом

```bash
mb status
mb probe
```

`probe` отдает адрес, заголовок, h1 и h2, видимые поля с подписями, видимые
кнопки и сообщения об ошибках. Дальше селекторы берутся из карты, а не из головы.

Если элемента нет в `probe`, он либо скрыт, либо внутри iframe. Скрытый элемент
не кликнется настоящей мышью, поэтому сначала надо понять, что его показывает.

## Клик, который действительно работает

```bash
mb do '[{"op":"click","text":"Отправить","expect":{"text":"Спасибо"}}]'
```

- клик идет настоящей мышью через CDP по центру элемента, а не через `element.click()`;
- `settle` по умолчанию 150 мс, увеличивайте до 400, если элемент анимируется;
- `expect` обязателен для всего, что меняет состояние. Клик без проверки это лотерея;
- если проверка не прошла, шаг повторяется один раз автоматически.

Ловушка: `input[type=submit]` не находится поиском по тексту кнопки. Ищите
по `sel`: `{"op":"click","sel":"input[type=submit]"}`.

Ловушка: JS-клик не проходит там, где обработчик висит на `mousedown` или где
кнопка в форме с проверкой. Настоящий клик мышью проходит.

## Формы

```json
[
  {"op": "fill", "label": "Имя", "value": "Герман"},
  {"op": "fill", "label": "Телефон", "value": "+7 ..."},
  {"op": "select", "label": "Город", "value": "Оренбург"},
  {"op": "check", "label": "Согласен с обработкой данных"},
  {"op": "fill", "sel": "textarea", "value": "текст письма"},
  {"op": "click", "text": "Отправить", "expect": {"text": "заявка принята"}}
]
```

`fill` ставит значение через нативный сеттер и шлет `input`, `change`, `blur`.
Этого достаточно для React и Vue. Если поле с маской (телефон, дата) не принимает
значение, используйте `type`: он вводит текст через CDP как клавиатура.

## Поля с маской и автоподстановкой

```json
[
  {"op": "click", "sel": "input[type=tel]"},
  {"op": "type", "value": "9988776655"},
  {"op": "press", "key": "Escape"}
]
```

`press` нужен, чтобы закрыть выпадающий список подсказок: он перекрывает кнопку
отправки и клик уходит в подсказку.

## Многошаговый сценарий с проверками

```json
[
  {"op": "open", "url": "https://site.ru/orders"},
  {"op": "wait", "text": "Заказы", "timeout": 10},
  {"op": "click", "text": "Новый", "expect": {"url": "/orders/new"}},
  {"op": "fill", "label": "Название", "value": "Тест"},
  {"op": "click", "text": "Сохранить", "expect": {"gone": "Новый"}},
  {"op": "shot", "path": "result.png"}
]
```

## Чтение данных со страницы

```bash
mb do '[{"op":"extract","sel":"table tbody tr td:first-child"}]'
mb do '[{"op":"attr","sel":"a.next","name":"href"}]'
mb do '[{"op":"js","code":"[...document.querySelectorAll(\".price\")].map(e=>e.innerText)"}]'
```

`extract` возвращает список текстов, `js` любой результат, сериализуемый в JSON.

## Скриншот

```bash
mb shot page.png
```

Снимается видимая область рабочей вкладки. Перед снимком полезно
`{"op":"scroll","to":"top"}`, иначе в кадр попадет случайное место.

## Вкладки

```bash
mb tabs
mb use 123456
```

Звездочка в `mb tabs` показывает рабочую вкладку. Все команды без явной вкладки
работают с ней.

Не закрывайте вкладку `http://127.0.0.1:8765/`: на ней держится связь
с расширением.

## Если расширение молчит

1. `mb status` покажет возраст последнего опроса.
2. Откройте вкладку `http://127.0.0.1:8765/` и прочитайте, что на ней написано.
3. Проверьте, что Marty Bridge включен на странице расширений.
4. `mb up` поднимет мост и вкладку, если их нет.

Расширение выключается при обновлении браузера и иногда после перезапуска
профиля. Это первое, что надо проверить.
