# Telegram: рабочие рецепты

Канал работает с установленным Telegram Desktop на Windows. Чтение идет
скриншотом, запись через буфер обмена.

## Посмотреть, что происходит

```bash
mb tg title                 # заголовок активного окна, это и есть имя чата
mb tg look "Имя чата" out.png
```

`look` открывает чат и сразу снимает окно. Дальше смотрите картинку: агент
с глазами читает текст с изображения. Заголовок окна подтверждает, что открыт
именно тот чат.

## Отправить текст

```bash
mb tg send "Избранное" "проверка связи"
```

Перед отправкой сверяется заголовок: если в названии чата нет строки, которую
вы передали, текст не уходит и команда возвращает ошибку. Это защита от промаха.

Если чат называется не так, как вы помните, сначала `mb tg look` с частью
названия: поиск в левой панели находит по подстроке.

## Отправить файл

```bash
mb tg sendfile "Имя чата" "C:\путь\файл.pdf"
```

Файл кладется в буфер через PowerShell и вставляется в поле ввода, потом Enter.
Если файл большой, отправка занимает время: после команды имеет смысл
`mb tg look` и убедиться, что вложение ушло.

## Ввести текст без отправки

```bash
mb tg paste "черновик"
```

Текст оказывается в поле ввода, но не отправляется. Дальше либо Enter руками
пользователя, либо `mb tg key enter`.

## Навигация

```bash
mb tg key ctrl+f        # поиск внутри открытого чата
mb tg key esc           # снять фокус с поиска
mb tg click 180 48      # клик по координатам внутри окна
```

Ловушка: `ctrl+f` ищет внутри чата, а не по списку чатов. Для перехода между
чатами используйте `mb tg open "Имя"`, он кликает по полю общего поиска.

## Чего не делать

- не отправляйте сообщения людям без прочитанного текста;
- не отвечайте в чаты работодателей от имени пользователя без его подтверждения;
- не удаляйте переписку и не выходите из чатов;
- не публикуйте скриншоты чатов без предупреждения: в кадр попадают имена,
  телефоны, номера заказов.

## Если окно не находится

1. Telegram Desktop запущен и не свернут в трей без окна.
2. `mb tg title` возвращает заголовок, а не ошибку.
3. Если канал отвечает «не хватает пакетов», установите `pip install -e ".[telegram]"`.

Окно ищется по процессу `Telegram.exe` и классу окна `MainWindow`, поэтому
несколько окон Telegram на машине не путаются между собой.
