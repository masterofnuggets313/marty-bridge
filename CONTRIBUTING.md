# Как участвовать

## Что приветствуется

- Новые шаги в драйвере (`mbridge/driver.py`), если они закрывают частый случай.
- Рецепты для агента в `prompts/`, проверенные на живой странице.
- Исправления обхода ловушек: усыпление воркера, выгрузка вкладок, маски полей.
- Тесты, которые ловят регресс без живого браузера.

## Чего не принимаем

- Обход капчи, детекта автоматизации, ограничений площадок.
- Скрытую отправку данных наружу.
- Команды, которые стирают чужое содержимое без подтверждения.

## Окружение

- Python 3.10 или новее.
- Браузер на Chromium для ручных проверок.
- Windows для канала Telegram, остальное кроссплатформенно.

```bash
python -m venv .venv
.venv\Scripts\activate      # Linux и macOS: source .venv/bin/activate
pip install -e ".[dev,telegram,cdp]"
python -m pytest -q
```

## Стиль кода

- типизация по возможности, `from __future__ import annotations`;
- комментарии по-русски, объясняют причину, а не пересказывают код;
- без внешних зависимостей в браузерной части: только стандартная библиотека;
- ошибки возвращаются словарем `{"ok": false, "error": "..."}`, а не трейсбеком.

## Проверка перед pull request

1. `python -m pytest -q` зеленый.
2. `mb status` на живом браузере показывает расширение и вкладку-сторож.
3. Сценарий из `mb do` отрабатывает на реальной странице.
4. В diff нет личных данных: телефонов, почты, id аккаунтов, скриншотов с чатами.

## Коммиты

Одна строка, по-русски, в прошедшем времени: «Добавил шаг extract для списков».
Без emoji и без приставки вида `feat:`.
